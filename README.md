# customer-registration-web-csharp

Aplicação web desenvolvida em C# para cadastro e gerenciamento de clientes por meio de um navegador.

## Sobre o Projeto

Aplicação web desenvolvida em C# para cadastro e gerenciamento de clientes por meio de um navegador.

## Tecnologias Utilizadas

- C#
- ASP.NET Core MVC / Razor Pages (conforme implementação)
- HTML5
- CSS3
- Bootstrap
- SQL Server ou PostgreSQL

## Funcionalidades

- Navegação por páginas web
- Formulários de cadastro e edição
- Validação no cliente e no servidor, quando implementada
- Listagem responsiva de clientes
- Paginação, quando implementada

## Arquitetura do Projeto

Arquitetura MVC (Model-View-Controller) ou Razor Pages, conforme a estrutura efetivamente utilizada no projeto.

## Banco de Dados

SQL Server ou PostgreSQL, conforme a configuração da aplicação.

## Como Executar

1. Clone este repositório.
2. Abra a solução no Visual Studio ou IDE compatível com .NET.
3. Configure a connection string do banco de dados.
4. Verifique e aplique as migrations ou scripts necessários.
5. Restaure os pacotes NuGet, compile e execute a aplicação.
6. Acesse pelo endereço local informado pela aplicação.


## Aprendizados

- Desenvolvimento de aplicações web com C# e ASP.NET Core.
- Construção de interfaces com HTML, CSS e Bootstrap.
- Validação de formulários no cliente e no servidor.
- Integração entre aplicação web e banco de dados.
